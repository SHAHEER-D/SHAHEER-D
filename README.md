### About me

I'm a **DevOps Engineer** with an Electrical Engineering background. I like knowing how a system actually behaves underneath, from the network and storage up to the service, not just the API on top.

Day to day at **US Consulting Services** I build CI/CD pipelines in GitHub Actions, containerize ETL and analytics workloads with Docker, and manage AWS infrastructure with Terraform for a live Snowflake-based client engagement. Before that I was an **AI Engineer at Flow9**, training and deploying ML and LLM models. My hardware roots (RISC-V and UVM-SV verification) taught me to test systems properly before trusting them in production.

**Open to remote DevOps, Cloud, Platform and Data Engineering roles.**
